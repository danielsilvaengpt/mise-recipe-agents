# Mise — Aplicação Python (CrewAI, FastAPI, Streamlit)

Esta pasta é dedicada ao backend e aplicação interativa do **Mise**:

- **CrewAI**: Orquestração da brigada de agentes de IA (Chef criativo, Redator de receitas e Revisor de segurança).
- **FastAPI**: Endpoints e API para gestão de despensa e processamento de receitas.
- **Streamlit**: Interface interativa de utilizador para registo de alimentos e geração de receitas em tempo real.
